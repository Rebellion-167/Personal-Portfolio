## 🛠️ How It Was Built
This portfolio is built completely from scratch using clean, modern web technologies:

*   **Build Tooling:** Powered by **[Vite](https://vitejs.dev/)** for fast development, structured building, and asset optimization.
*   **Design & Layout:** Styled with premium, customized **Vanilla CSS**. Features a custom glassmorphism design language using custom colors, smooth `cubic-bezier` animations, CSS custom properties, and fluid typography.
*   **Interactivity & Core Logic:** Built with native **Vanilla JavaScript** (ES modules). Interactivity includes:
    *   An interactive particle constellation background on an HTML5 `<canvas>`.
    *   A custom typewriter animation.
    *   A scroll-based scroll-reveal effect powered by the native browser `IntersectionObserver`.
    *   A dynamic project filter matching category badges.
    *   Custom indicator-underline animations that slide and snap on navbar links.
*   **Icons & Assets:** Icons are served dynamically using **[Lucide Icons](https://lucide.dev/)**.
*   **Form Integration:** Integrated with **[Formspree](https://formspree.io/)** for client-side contact email routing.
*   **Hosting & Deployment:** Automatically built and hosted globally via **[Vercel](https://vercel.com/)**.
